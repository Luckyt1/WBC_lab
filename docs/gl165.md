任务名为 `walk_gl165_wbc`，使用用户提供的 `gl_165.urdf`。

## 任务与约束

按本次要求，策略控制腰部 3 个、双腿 12 个关节；双臂 14 个关节执行外部 IK 轨迹，头部保持默认姿态。
命令只有 `vx / vy / wz`，没有腰部姿态追踪，也没有高度指令或高度追踪奖励。
根部高度低于 0.55 m 只作为跌倒终止条件。根部倾斜、非足部接触也会触发终止。

姿态约束使用软惩罚：胸部 `body_y_link` 相对世界竖直方向的倾斜（权重 -3）；
腰部偏航超出 ±15°、横滚/俯仰超出 ±8° 的部分（权重 -2），另加腰关节速度惩罚（-0.02）。
站立时双腿偏离默认姿态的容差带后增加轻微惩罚（-0.5），屈膝超过 60° 增加深蹲惩罚（-2）。
行走时深蹲惩罚只作用于接触地面的支撑腿，阈值为 75°，摆动腿可正常屈膝抬脚。
这些角度是惩罚起点，不是关节硬限位；没有固定站高或腰部追踪指令。
日志中的 `Posture/` 指标在自动重置前记录胸部倾角、腰角、屈膝程度与骨盆高度。

仅当速度指令 `vx / vy / wz` 全为零（各分量数值容差 `1e-6`）时，增加足底负重不足惩罚（权重 -2）：
分别计算每只脚竖直支撑力低于 150 N 的归一化缺口，再取两脚平均；一脚多承重不能抵消另一脚的不足。
它依据速度指令判定，站立时被手臂扰动推得晃动仍然生效；非零行走或转向指令下关闭。
这是软惩罚，不是力的硬限位。`FootLoad/` 日志记录零指令环境的左右脚平均负重及双脚同时达标比例。

行走、侧移和转向时增加双脚间距过大惩罚（`moving_feet_distance`，权重 -2）：
取左右 `foot_x_link` 原点在水平面上的距离 `d`，惩罚 `max(d / 0.40 - 1, 0)²`。
40 cm 是软惩罚起点，不是强制截断脚的位置；另有下面的横向步宽容差带。
抬脚高度不计入距离，但摆动脚仍参与计算，避免用悬空绕过约束。
仅在速度指令至少一个分量超出 `1e-6` 时启用；零指令站立保留已有姿态和足底负重约束。
`FootSpacing/` 记录移动时的水平脚间距、横向步宽、超限比例和超限距离，均在自动重置前测量。
`scripts/play_gl165.py --show-foot-spacing` 可在预览里显示真实比例的蓝色 40 cm 参考尺（每格 10 cm），
以及实际双脚水平距离线：40 cm 内为绿色，超出为红色。标记只有显示作用，不产生碰撞或改变机器人状态。

另加足部朝向和髋部扭转软惩罚，避免躯干朝前、双腿拧向同一侧的“螃蟹步”：
`feet_heading`（权重 -2）比较每只脚实际 +X 轴与骨盆前向的水平夹角，超过 15° 的部分按弧度平方取两脚平均。
基准随骨盆转动，不使用行进速度方向，因此允许脚尖朝前地侧移、倒退及随身体转向。
正常抬脚俯仰不计入偏航；脚尖接近竖直时对水平投影长度使用 0.1 下限，避免投影退化绕过惩罚。
`hip_yaw_range`（权重 -0.5）惩罚髋偏航相对默认姿态超过 ±20° 的部分。
默认姿态包含 URDF 倾斜髋轴所需的补偿角，不把髋关节机械零位当作脚尖朝前。
两项在站立、移动时均生效，不是硬锁定。`FootHeading/` 记录左右脚偏角、移动时超过 30° 的比例及髋部扭转。
评估脚本同步记录脚尖朝向、胸部相对骨盆的朝向和髋偏航，避免仅凭存活率与速度判定步态合格。

为避免固定右脚在前的小步挪动，新增以下软约束：

- `feet_lateral_band`（-2）：在骨盆水平坐标系中使用**左脚减右脚的有符号 Y 距离**，
  容差为 16–26 cm，带外距离除以 10 cm 后平方。负值代表交叉，不能通过取绝对值隐藏。
  站立、行走及摆动脚均参与，允许容差带内自由调整。
- 可观测的步态时钟：周期 0.9 s，左右相差半周期，支撑相占 60%，含双脚支撑过渡。
  随机初始相位避免固定一侧先迈步。起步参考在 0.3 s 内渐入，停步在 0.4 s 内渐出。
  `gait_contact`（-1）检查支撑/摆动相与竖直接触力是否相符，在触地切换前后各留 0.03 周期容差。
  原先不区分迈步相位的 `feet_air_time` 奖励关闭。
- `gait_clearance`（-0.5）：摆动相用平滑曲线给出最高 6 cm 的离地参考，误差除以 4 cm 后平方。
  足部原点在水平脚底上方 3.2 cm；只约束摆动脚，不是身体高度控制，也不要求支撑脚追踪高度。
- `gait_fore_aft`（-1）：前进/后退时，两脚的前后位置随步态相位交替，步幅按 `vx × 周期 × 支撑相比例`
  缩放，前后参考差不超过 30 cm。使用 2 cm 误差容差、8 cm 归一化尺度。
  纯侧移、纯转向和站立关闭此项；`|vx|` 在 0.05–0.1 m/s 之间平滑启用。
- `stand_foot_alignment`（-1）：停止后先留出 0.4 s，再用 0.6 s 逐渐启用收脚惩罚；
  两脚前后差在 ±6 cm 内不扣分，超出部分除以 10 cm 后平方。站立初始化直接使用完整权重。
  保留零指令时每脚 150 N 的软负重约束。

这些参考只用于奖励，不直接修改关节目标或强制移动脚。胸部、腰部、膝盖和 40 cm 总间距约束保留。
`Gait/` 记录交替参考误差、左右领先比例、领先脚切换频率与停稳后的前后差；
`FootSpacing/` 新增有符号步宽和交叉比例，评估记录同样保留左右方向。

## 本机启动

```bash
cd /path/to/WBC_lab
bash scripts/train_gl165.sh
```

默认使用已有的 `~/miniconda3/envs/isaac_wbc/bin/python`，不会重新安装或切换其他项目的 editable 包。
训练脚本将当前仓库及其 `rsl_rl/` 放在 Python 导入路径最前。
其他机器可通过 `GL165_PYTHON=/path/to/python` 指定 Isaac Lab Python。

`.env.example` 提供可选的 `GL165_PYTHON`、`GL165_ASSET_DIR` 和 `GL165_IK_BANK` 配置。
`.env` 不会自动加载；编辑后在当前终端执行 `set -a; source .env; set +a`。

默认 4096 个并行环境、50,000 次 PPO 更新、每 500 次保存，日志使用 TensorBoard。
每次启动创建新的 `logs/gl165_wbc/<时间戳>/`，默认从零训练。

```bash
# 短训练验证
bash scripts/train_gl165.sh --num_envs 128 --max_iterations 10 --run_name smoke

# 正常训练，可调整环境数量和训练长度
bash scripts/train_gl165.sh --num_envs 4096 --max_iterations 50000 --run_name ik_disturbance

# 从这个任务自己的检查点恢复；max_iterations 是本次新增更新数
bash scripts/train_gl165.sh --resume True \
  --resume_checkpoint /absolute/path/model_500.pt --max_iterations 10000

# 观察训练曲线
~/miniconda3/envs/isaac_wbc/bin/tensorboard --logdir logs/gl165_wbc
```

## 可视化手臂扰动

在桌面会话中运行，默认一个机器人、零速度站立命令、双臂连续 IK 扰动：

```bash
export LD_PRELOAD="$HOME/miniconda3/envs/isaac_wbc/lib/libstdc++.so.6${LD_PRELOAD:+:$LD_PRELOAD}"
~/miniconda3/envs/isaac_wbc/bin/python scripts/play_gl165.py \
  --checkpoint /absolute/path/model_1000.pt --command 0 0 0
```

`--command 0.3 0 0` 可观察前向行走；`--arm-group left/right/all` 可选择其他扰动组合。
可视化使用检查点旁的 `params/agent.yaml` 加载网络，关闭观测噪声、外部推扰及重置随机化。
播放、评估和显式续训会从 `params/env.yaml` 恢复步态时钟配置。没有 `gait` 配置的旧模型
仍使用原来的 820/1010 维观测和旧步态奖励；新增时钟的模型使用 860/1050 维观测。
新的默认训练从随机权重开始，不能把旧网络权重直接加载到新输入维度。
展示与新版训练都使用连续动作，侧方目标的采样比例为 30%，过头顶为 20%。
仿真以实际时间播放，关闭窗口即可停止展示，不会停止训练。

### MuJoCo 单独查看手臂扰动

```bash
.venv-gl165-mujoco/bin/python scripts/play_gl165_mujoco.py
```

这个窗口固定躯干、腰、双腿和头部，只对双臂进行物理仿真，不加载训练策略。
使用训练库及同一个 `ContinuousIkArmMotion` 播放器，复用关节 PD、力矩限幅、50 Hz 参考更新与 200 Hz 物理步长。
默认混合左臂、右臂和双臂动作，执行“目标 A → 平滑过渡 → 目标 B”。
动作间没有准备、保持、收回或休息阶段；只在环境重置时从初始关节姿态连接到第一个目标。
蓝色、橙色圆点分别标记左右腕的下一个目标，切换动作时圆点会移动。
左上角显示到下一目标的当前距离和上一目标的到位误差（厘米），两者含义不同。
目标对应腕部坐标原点，不是指尖；连续模式的到位误差在过渡终点的一帧测量。
空格暂停或继续，`R` 重置并选择新目标，鼠标拖动和滚轮调整视角。
`--arm-group left/right/both/all` 可选择动作组合；`--target-region overhead` 可只看过头顶动作，
`--target-region lateral` 可只看侧方动作。
这是手臂扰动预览，不能用来判断策略的站立或行走能力。

本机已在独立 `.venv-gl165-mujoco/` 中安装 MuJoCo 3.17.0；复用 Isaac Python 的 NumPy、PyTorch 等依赖。
重建这个预览环境可执行：

```bash
~/miniconda3/envs/isaac_wbc/bin/python -m venv --system-site-packages .venv-gl165-mujoco
.venv-gl165-mujoco/bin/python -m pip install -r requirements/gl165-mujoco.txt
.venv-gl165-mujoco/bin/python scripts/play_gl165_mujoco.py \
  --headless --seconds 30 --report output/gl165_mujoco/arms_validation.json
```

首次运行从训练 URDF 生成 `resources/gl165/mujoco/gl165_arms.xml`，原始文件保持原样。
网格转换为 OBJ，保留惯量、质量及训练中的装配碰撞过滤；仅保留 14 个活动手臂关节。
固定躯干后，显式保留原 URDF 的所有相邻连杆碰撞过滤，避免肩部电机外壳与胸腔发生内部碰撞。
MuJoCo 对与世界固定连接的父连杆不自动过滤其活动子连杆，见 [碰撞过滤规则](https://mujoco.readthedocs.io/en/3.17.0/computation/index.html#collision-detection)。
URDF 导入选项依据 [MuJoCo 官方 XML 文档](https://mujoco.readthedocs.io/en/3.17.0/XMLreference.html)。
MuJoCo 与 PhysX 的接触、关节驱动求解器不同，实际跟踪误差不用于代替训练侧验证。

### 策略评估与录像

以下入口读取检查点旁的 `params/env.yaml` 和 `params/agent.yaml`，使用指定轨迹库的测试集。
评估输出目录必须尚不存在，避免覆盖已有结果。

```bash
"$GL165_PYTHON" tools/evaluate_gl165_policy.py \
  --checkpoint /absolute/path/model_1000.pt \
  --bank /absolute/path/ik_bank_continuous_lateral_v3 \
  --output output/gl165_eval_new --profile controlled --headless

# 录像额外依赖，版本取自已使用的本机环境
"$GL165_PYTHON" -m pip install -r requirements/gl165-video.txt
"$GL165_PYTHON" tools/record_gl165_policy.py \
  --checkpoint /absolute/path/model_1000.pt \
  --bank /absolute/path/ik_bank_continuous_lateral_v3 \
  --output output/gl165_video_new --headless
```

`controlled` 配置关闭观测噪声、外部推扰和重置随机化；`--profile training` 使用训练环境的随机项。
两种配置分别记录结果，评估在自动重置前采样，失败后的机器人不再进入该次试验统计。
录像需要可用的 Isaac 渲染环境；MuJoCo 手臂预览不加载策略，不能替代此评估。

IK 库由 GL-165 自身手臂运动学生成，包含 456 个训练目标和 114 个测试目标。
原有 256 / 64 个前方为主的目标，以及此前加入的 80 / 20 个过头顶目标保持原样。
过头顶动作覆盖左手举高、右手举高、双手举高、左高右低、右高左低。
目标相对 `body_y_link`；举高腕部的目标至少超过默认头顶 6 cm，离线动力学验证的实际腕部超过头顶 2 cm。

新增 120 / 30 个侧方目标，覆盖左侧伸、右侧伸、双臂侧伸，以及一侧伸展、另一侧前伸的组合。
每种组合均包含侧下方、肩部高度和侧上方三个高度层。
侧伸手腕相对同侧肩部向外 35–53 cm，前后偏移在 -12 至 16 cm 内；三个高度层相对肩部为
[-22, -8]、[-6, 8]、[13, 25] cm。左右侧方覆盖独立检查，避免仅通过提高前侧目标采样率来填补缺口。

新版 `ContinuousIkArmMotion` 按 50% 普通目标、30% 侧方目标、20% 过头顶目标采样，每个区域内均衡左臂、右臂、双臂组。
这是目标选择的比例；由于举高手臂的过渡更慢，所占播放时间可能更长。
任意一个目标都有 18 条预先检查过的出边，共 8208 条训练过渡和 2052 条测试过渡。
旧库的 5040 条过渡保持原样，另筛选了 5220 条涉及侧方目标的新过渡。
目标间用关节空间五次曲线直接连接，端点速度和加速度为零，不插入回中、保持或休息阶段。
过渡时长至少 2 s，普通过渡按 1.2 rad/s、3 rad/s² 限制，涉及举高手臂时按 0.8 rad/s、2.5 rad/s² 限制，
每次再乘以 1.0–1.25 的随机时间系数。运行时保留 2 rad/s 的参考位置变化硬上限。

所有过渡按最大关节间隔 0.02 rad、每条至少 65 个姿态检查碰撞；新增目标还检查完整抬臂路径的 PD 跟踪、力矩和碰撞。
这些离线检查固定躯干和双腿，不能保证行走和身体倾斜时所有姿态都无自碰撞，训练侧仍开启自碰撞处理。
不使用实时腰部补偿、到位门控或重力前馈；实际到位误差记录为 `IK/endpoint_wrist_position_error_m`。
到位误差和 5 cm 成功率按本次运行中累计到位样本统计，`IK/endpoint_count` 是累计样本数。
`IK/overhead_sample_fraction` 记录目标采样比例，`IK/overhead_target_fraction` 记录当前执行举高目标的环境比例。
`IK/lateral_sample_fraction` 和 `IK/lateral_target_fraction` 分别记录侧方目标的采样与当前执行比例。

重建扩展库需使用 MuJoCo Python，并指定不存在的新输出目录：

```bash
.venv-gl165-mujoco/bin/python tools/extend_gl165_ik_bank.py \
  --source resources/gl165/ik_bank --output resources/gl165/ik_bank_overhead_new
.venv-gl165-mujoco/bin/python tools/extend_gl165_lateral_bank.py \
  --source resources/gl165/ik_bank_overhead_new --output resources/gl165/ik_bank_lateral_new
GL165_IK_BANK="$PWD/resources/gl165/ik_bank_lateral_new" \
```

## 训练配置与验证

| 项目 | 配置 |
| --- | --- |
| 物理 / 控制周期 | 5 ms / 20 ms |
| 策略动作 | 腰腿 15 维 |
| Actor 观测 | 10 帧 × 86 维 = 860 |
| Critic 观测 | 10 帧 × 105 维 = 1050 |
| 站立指令比例 | 50% |
| 速度范围 | vx [-0.5, 0.6] m/s；vy ±0.3 m/s；wz ±0.8 rad/s |
| 回合上限 | 40 s |
| PPO | 24 步采样；5 epoch；4 minibatch；自适应学习率 0.001 |
| Actor / Critic 网络 | [512, 256, 128]，ELU |

Actor 观察根部角速度、重力方向、三维速度命令、腰腿与双臂实际关节状态、上一动作，
以及 4 维无噪声步态状态：渐入/渐出后的相位正弦、余弦、活动权重和停步收脚权重。
Critic 额外观察根部线速度、双足接触及双臂参考位置。
奖励包括速度追踪、站立静止与双脚接触、站立漂移惩罚、直立平衡、滑步与控制平滑度。
质量、摩擦、重置状态和水平推扰进行随机化。
